# LearnML 🤖

Learn machine learning from scratch with practical examples and clear explanations.

## 📚 Overview

This repository provides a comprehensive introduction to machine learning fundamentals. It includes hands-on examples covering essential ML concepts, from data preprocessing to supervised and unsupervised learning algorithms.

## 🎯 What You'll Learn

- **Fundamental ML Concepts**: Understanding features, targets, training, and testing
- **Supervised Learning**: Regression and classification techniques
- **Unsupervised Learning**: Clustering algorithms
- **Data Preprocessing**: Handling missing values, scaling, and encoding
- **Model Evaluation**: Metrics and performance assessment

## 📁 Repository Structure

```
LearnML/
```

## 🚀 Getting Started

### Prerequisites

- Python 3.7 or higher
- pip (Python package manager)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/venkata-ram/LearnML.git
cd LearnML
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

### Running Examples

Navigate to any example directory and run the Python script:

```bash
# Introduction to ML concepts
python examples/01_introduction/introduction.py

# Linear regression example
python examples/02_regression/linear_regression.py

# Classification example
python examples/03_classification/classification.py

# Clustering example
python examples/04_clustering/kmeans_clustering.py

# Data preprocessing
python examples/05_data_preprocessing/data_preprocessing.py
```

## 📖 Topics Covered

### 1. Introduction to Machine Learning
- What is machine learning?
- Types of machine learning
- Working with data and features
- Basic data visualization

### 2. Linear Regression
- Simple linear regression
- Model training and prediction
- Performance metrics (MSE, R²)
- Visualization of results

### 3. Classification
- Binary classification with logistic regression
- Confusion matrix and accuracy
- Model evaluation metrics
- Decision boundaries

### 4. Clustering
- K-Means clustering algorithm

- Cluster visualization

### 5. Data Preprocessing
- Handling missing values
- Feature scaling (Standardization and Normalization)
- Encoding categorical variables
- Feature engineering basics
